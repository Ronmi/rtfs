**5. Known limitations (accepted for now):**
- Panels/dialogs opened on eDP-1 while an external output is focused get no keyboard focus (niri gives layer focus only on the active output); click outside still closes. Dialogs open on the focused output to avoid it. The launcher (2026-11-10) opens on every screen with the same cells per page (set by the bar screen at base cell size; each screen picks its own columns×rows with the largest cell scale, e.g. 5×9 on a portrait screen; screens needing scale < 0.8, like a planned strip touchscreen, or listed in `launcher.excludeOutputs` get a click-to-close mask instead) and calls `Niri.focusMonitor` on any press, so keyboard follows the screen being used; first frame ~200–250 ms with two screens vs ~90 ms with one (user tried it 2026-11-10: acceptable).
- Notification center rebuilds its list when a notification arrives, so a half-typed inline reply there can be lost. Notifications are not persisted across qs restarts.
- fuzzel is still installed and `theme-gen` still writes its colors, but nothing calls it; can be removed later (niri project).

**Not issues (user said so, don't "fix"):** network rate block width changing (module order already accounts for it), tray icon order.
